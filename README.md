# Strokehaven 1.0 TEST
Native Java/Canvas Android 8+ Juosan directional-stroke puzzle.

Every cell holds a horizontal or vertical stroke. A room clue is the larger of its horizontal and vertical stroke counts; ties are allowed. Three vertical strokes side by side in a row are forbidden. Three horizontal strokes stacked in a column are forbidden. These run rules continue across room borders. Long runs along a stroke's own direction are allowed. Every cell starts horizontal; tap to switch direction. Twelve unique 4x4 rectangular-room boards have twelve distinct solutions. Every room is numbered in this edition.

Saved stroke palette and room guides, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, account or requested permissions. Settings and completed-puzzle marks stay on device. External studio link opens browser.

Independent Java builds per-room Boolean lists and scans directional runs along coordinates. All 65536 complete assignments per board agree with production room counts and sliding triple tests. Exactly one solution per board; bounds, solve, undo and replay pass. Adapter navigation, saved settings, privacy, cell taps, next, levels and persistence pass. Actual drawing pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only; not final or Play published.

Current 803-entry registry, 122 partial recovered README records and exact Threadhaven cumulative stage found no Juosan or directional-stroke-majority match. Shares two-state cell tapping with Pairbloom and Binarybrook Takuzu, but removes row/column balance, line uniqueness and symmetric no-triples, replacing them with room-majority counts and orientation-specific forbidden triples. Shared Aqre run-limits are disclosed, but no shading connectivity or fixed dark quotas apply. Unlike Threadhaven there are no paths, endpoints or connectivity. Known Juosan genre, not a global invention. Partial recovered corpus, not ALL-local. Rules https://www.nikoli.co.jp/en/puzzles/juosan/ .
